## About

I'm a software engineer with over a decade of experience building products that scale — from early prototypes to production systems used by real people. I care less about the tools and more about the outcome: software that is fast, reliable, and genuinely useful.

I lean into the full stack, but my roots are in **backend engineering** with Node.js and TypeScript. I'm drawn to the intersection of good engineering and good product thinking — the place where clean architecture meets user impact.

When I'm not building, I'm experimenting. New stack, new idea, new side project — it's how I stay sharp.
